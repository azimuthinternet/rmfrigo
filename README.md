# RM Frigo — Website

Current static website preview/source for RM Frigo Rijeka.

## Pages

- `index.html` — homepage
- `prodaja-klima-uredaja.html` — Service / informational template
- `mitsubishi-electric.html` — Mitsubishi Electric brand page
- `piazzetta.html` — Piazzetta brand page
- `ventilacija.html` — ventilation page

## Assets

- `css/` — page styles extracted from the working HTML templates
- `js/` — page scripts extracted from the working HTML templates

## Templates

- Homepage: dedicated homepage template
- Brand/product pages: product/brand template
- Services, About and other non-brand pages: Service / Informational Template (V59)
- Header and footer are global site components and should remain consistent across the site.

## WordPress

This static project is the current visual/structural basis for the final WordPress implementation.
